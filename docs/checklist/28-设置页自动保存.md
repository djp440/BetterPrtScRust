# 验收清单：#28 设置页自动保存（已通过）

自动化已覆盖的部分（`crates/ui/src/autosave.rs`，5 项）：
- 点一下（复选框、下拉框）立即保存，并且只存一次。
- 连续输入时一次都不存，停下 500 ms 后才存一次。
- 离开输入框时不再等待，立即保存。
- 不合法的值不保存，改正后才保存。
- 改动后又改回原值时不写文件。

写入原子化（先写临时文件再改名）和“被别处改过就不覆盖”沿用原来的 `store`，已有测试。

下面只留需要人眼和手动操作判断的项。打开设置的方法：托盘菜单 → 设置。如果常驻实例还是旧版本，在仓库目录运行 `target\debug\BetterPrtSc.exe --settings`，它会编辑同一份配置。

- [x] **1. 下拉框、复选框改完立即生效**
  - 操作：用记事本打开 `%APPDATA%\BetterPrtSc\config.toml`。在设置里勾选或取消“识别后自动复制”，再把截图格式改成 JPEG，然后在记事本里重新打开文件查看。
  - 预期：
    - 界面上已经没有“保存”和“撤销修改”按钮。
    - 每次改动后，底部马上出现“已保存，立即生效。”。
    - 文件里对应的行已经变了，文件里原有的注释和排版都还在。
  - 用户反馈：

- [x] **2. 文本框停下输入后才保存**
  - 操作：在“截图与保存”分组的“文件命名”里连续打几个字，停下等 1 秒，再看 `config.toml`。
  - 预期：
    - 打字过程中“已保存”提示不会每打一个字就闪一次。
    - 停下约半秒后保存一次，文件里是完整的新模板。
  - 用户反馈：

- [x] **3. 不合法的值就地提示，不写入**
  - 操作（两项分别做）：
    - 在“热键”里把两条绑定录成同一个组合键；
    - 在“文件命名”末尾加一个 `{`（占位符没闭合）。
  - 预期：
    - 出错的那一项旁边标红提示。
    - 底部显示“标红的修改不合法，没有保存；配置仍是上一次的有效值。”。
    - `config.toml` 里还是之前的值。
    - 改回合法值后自动保存。
  - 用户反馈：

- [x] **4. 关闭再打开，改动都还在**
  - 操作：随便改几项，最后一项是在文本框里打字，打完立刻关掉窗口（不等半秒）。然后重新打开设置。
  - 预期：
    - 关闭时没有弹窗。
    - 重新打开后，所有改动（包括最后打的字）都在。
  - 用户反馈：

- [x] **5. 有不合法的修改时关闭**
  - 操作：在“文件命名”末尾留一个 `{`，然后关闭窗口。
  - 预期：
    - 弹出“有未保存的修改”，说明这些修改没能保存，关闭后会丢失，按钮是“仍然关闭”和“取消”。
    - 点“仍然关闭”后，`config.toml` 还是上一次的有效值。
