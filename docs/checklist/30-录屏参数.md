# 验收清单：#30 录屏参数（编码、麦克风、码率）

自动化已覆盖的部分：
- 配置的全局默认和每条绑定的覆盖规则、错误提示（`config_parsing.rs`）。
- 设置界面数据的读取与写回（`settings_document.rs`）。
- 端到端（`recording_parameters.rs`，23 项）：麦克风与系统声音混在同一条音轨；麦克风找不到时回退默认设备、打不开、中途断开时的通知；控制条声音开关在录制中途静音、恢复，只影响当前这段录屏；GIF 没有声音开关；编码选择和不支持时退回 H.264；画质档位、自定义码率、H.265 / AV1 码率更低、帧率影响码率。

真机冒烟：
- `audio_smoke`：麦克风按默认设备和按设备标识都能采集。
- `video_smoke`：用每种可用的编码录 1 秒并解码检查。

这台电脑的实测情况：
- H.264 能录、能解码。
- H.265 能录，但系统里没有 HEVC 解码器（需要“HEVC 视频扩展”）。
- AV1 编码器能建好，但写完文件时失败，自检判为不可用，设置界面里置灰。

下面只留需要人眼、人耳和手动操作判断的项。

- [x] **1. 设置界面“录屏”分组**
  - 操作：托盘菜单 → 设置 → 左侧“录屏”，依次查看并试着改动各项（先不保存）。
  - 预期：
    - 分组里有帧率、录制鼠标指针、视频编码、画质（低 / 标准 / 高 / 自定义码率）、录入系统声音、录入麦克风和麦克风设备下拉框，布局整齐、文字没有截断。
    - 打开分组时编码框旁边短暂转圈（在检测）。检测完后 AV1 置灰，鼠标悬停能看到原因，下方有一行“AV1 不可用：…”。
    - 选 H.265 时出现提示“系统播放器放不了 H.265 视频，需要装 HEVC 视频扩展或换用其他播放器”。
    - 麦克风下拉框里能看到“系统默认麦克风”和你的麦克风名字（MC001）。
    - 改动后“保存”可点；保存后打开 `config.toml`，能看到对应的 `video_codec`、`video_quality` / `video_bitrate`、`record_microphone`、`microphone` 等行。
  - 用户反馈：

- [x] **2. 麦克风和系统声音混录**
  - 操作：在设置里勾选“录入麦克风”并保存。播放一段有声视频，录屏时对着麦克风说几句话，录 15 秒左右后停止，用播放器打开 MP4。
  - 预期：同一条音轨里既有播放的声音也有你的说话声，两者都清楚、音画同步。
  - 用户反馈：

- [x] **3. 控制条上的声音开关**
  - 操作：录屏时，控制条上的“系统声音”“麦克风”各点一次关掉（文字变灰、带删除线），说话、放声音几秒后再点开，然后停止。
  - 预期：
    - 关掉的那几秒对应的声音不在视频里，打开后恢复。
    - 控制条本身没有出现在录出的画面里。
    - 下一次录屏的开关又回到设置里的状态。
  - 用户反馈：

- [x] **4. 画质档位改变文件大小**
  - 操作：画质分别选“低”和“高”，录同一段内容变化较多的画面（例如滚动网页或播放视频）各 10 秒，比较两个 MP4 的大小。
  - 预期：“高”的文件明显比“低”的大（理论码率相差 4 倍）；两段都能正常播放。
  - 用户反馈：

- [x] **5. H.265 录屏能播放**
  - 操作：编码选 H.265 并保存，录 10 秒。用能播放 HEVC 的播放器打开（例如 VLC / PotPlayer），或者在 Microsoft Store 安装“HEVC 视频扩展”后用系统播放器打开。
  - 预期：画面和声音正常；同样画质下文件比 H.264 小一些。
  - 用户反馈：

- [x] **6.（可选）选中的麦克风不在时回退**
  - 操作：在设置里选定 MC001 并勾选录入麦克风，保存后拔掉这个麦克风（或在系统声音设置里禁用它）再录一段。
  - 预期：开始录制时托盘通知“录屏改用默认麦克风”或“录屏没有麦克风声音”（没有其他麦克风时），录制照常进行。验收完恢复设备。
  - 用户反馈：
