# 验收清单：#27 合并区域与窗口模式（已通过）

自动化已覆盖的部分：
- 端到端测试（`crates/core/tests/`，假平台）：
  - 单击窗口：复制模式立即复制窗口完整内容；等待确认时标注窗口截图；Enter 选中高亮窗口。
  - 拖过阈值才框选：抖动 4 像素以内仍算单击，5 像素就是框选；150% 缩放下阈值放大到 6 像素；跨两个窗口拖拽得到区域。
  - 按下和松开在两个窗口上、又没拖过阈值：什么也不选。
  - 录屏：单击窗口后要 Enter 才开始，录的是窗口本身（被遮挡的部分也完整）；在窗口上拖拽录的是区域。
  - 长截屏：单击窗口，选区就是窗口范围，仍要点“开始”。
  - OCR：单击窗口立即识别窗口内容。
  - 旧的 `mode = "window"`：报出指向该行、提示改成 `region` 的错误，配置回退到默认值；`bps capture window` 按参数错误拒绝。
  - 默认的 Ctrl+PrtSc 是“区域 + 复制”，单击窗口即复制。
- 真机冒烟 `scripts/smoke-cli.ps1`（本机，单显示器，200% 缩放）：遮罩上按下、抖动 3 像素再松开，截到的是测试窗口（尺寸等于窗口外框，颜色正确），自动保存的文件名带窗口标题。

常驻实例已换成新的 release 版（托盘里的 BetterPrtSc）。下面只留需要人眼和手动操作判断的项。

顺序提示：你的配置因为第 1 项的错误会回退到默认配置，第 2–6 项用的正是默认热键（PrtSc、Ctrl+PrtSc、Alt+PrtSc……）。建议先看第 1 项的通知，接着做 2–6，最后再改配置文件（你的配置里只有 Ctrl+1、Ctrl+Alt+1 两条，改好后默认热键就不在了）。

- [x] **1. 旧配置的 `mode = "window"` 给出明确提示**
  - 背景：你的 `%APPDATA%\BetterPrtSc\config.toml` 里有一条 `hotkey = "Ctrl+Alt+1"`、`mode = "window"` 的绑定。
  - 操作：重启后看系统通知（或通知中心）；做完 2–6 项后，把这一行改成 `mode = "region"` 并保存，再试 Ctrl+Alt+1 单击窗口。
  - 预期：
    - 通知写明是第几行，并说明窗口模式已并入区域模式、要改成 `mode = "region"`。
    - 出错期间你的热键（Ctrl+1 等）暂时不起作用，只有默认热键可用。
    - 改完保存后自动重新加载，Ctrl+1、Ctrl+Alt+1 恢复可用，不再弹错误。
  - 用户反馈：

- [x] **2. 截图：悬停高亮、单击选窗口、拖拽框选**
  - 操作：按 Ctrl+PrtSc（新的默认值：区域 + 复制）。先在几个窗口上移动鼠标，再单击其中一个窗口；再按一次，从某个窗口里按下并拖出一块区域。
  - 预期：
    - 还没有选区时，鼠标下的窗口高亮：窗口以外变暗、窗口内侧有描边、左上角标出窗口尺寸。
    - 单击后遮罩立即关闭，剪贴板里是这个窗口的完整内容（被别的窗口挡住的部分也在）。
    - 拖拽得到的是框出的区域，边缘照常吸附；放大镜、尺寸标签和方向键微调都还正常。
    - 手稍微抖一下（几像素以内）仍算单击，不会变成一个很小的选区。
  - 用户反馈：

- [x] **3. 截图：等待确认时单击窗口**
  - 操作：按 PrtSc，单击一个窗口。
  - 预期：遮罩上显示这个窗口的截图和工具条，可以标注；按 Enter 或“确认”复制。工具条转入录屏时录这个窗口。
  - 用户反馈：

- [x] **4. 录屏、长截屏、OCR 单击窗口**
  - 操作：
    - 按 Alt+PrtSc，单击一个窗口，按 Enter 开始录几秒，期间拖动这个窗口，再按 Alt+PrtSc 停止。
    - 按 Ctrl+Shift+PrtSc（长截屏），单击一个可滚动的窗口（如浏览器），点“开始”后滚动，再点“完成”。
    - 按 Win+Shift+O（OCR），单击一个有文字的窗口。
  - 预期：
    - 录屏：单击后不会马上开始，按 Enter 才开始；录出的视频是这个窗口，窗口移动时画面跟着它。
    - 长截屏：选区就是窗口的范围，仍要点“开始”。
    - OCR：单击后立即打开结果面板，识别的是这个窗口的内容。
  - 用户反馈：

- [x] **5. 设置页的捕获模式下拉框**
  - 操作：托盘菜单 → 设置，查看任一热键绑定的捕获模式下拉框。
  - 预期：只有“显示器”“虚拟桌面”“区域”三项，没有“窗口”。
  - 用户反馈：

- [x] **6. 多显示器、混合缩放（本机只有一块显示器，需要你在多屏环境下验）**
  - 操作：在两块缩放比例不同的显示器（如 100% 和 150%）上，分别用 Ctrl+PrtSc 单击窗口、拖拽框选；再试一个横跨两块屏的窗口。
  - 预期：
    - 两块屏上的高亮框都贴合窗口边缘。
    - 两块屏上轻微抖动都算单击，明显拖动都开始框选。
    - 横跨两屏的窗口能整体选中并截全。
