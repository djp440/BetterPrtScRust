## 自动化覆盖

- `ui_shortcuts.rs`：默认 OCR / 翻译按键在框选后、标注后分别触发；自动复制开关；文字输入保护；自定义按键、配置重载和实际 tooltip；保留按键、全局按键及两个界面按键之间的冲突；旧配置冲突时保留原全局热键和文件，仅禁用冲突的新增默认键并通知。
- 翻译自动复制：只复制译文；未配置、超时、服务错误、空译文时保留原剪贴板，不弹面板；错误中屏蔽密钥。工具条与界面快捷键都传递相同的翻译及自动复制参数。
- `annotation_resize.rs`：标注保持屏幕位置；缩小裁剪后再展开恢复；拖动不误画标注；按真实顺序撤销、重做；文字先提交再调整；窗口底图、身份、标题及录屏目标随撤销重做恢复；吸附、跨边翻转、负坐标高缩放显示器边界；手柄双击不阻塞历史。
- 普通区域历史只保存范围，撤销时从同一冻结帧重裁，不为每步保留整份裁剪底图；窗口原图共享保存。

- [ ] **1. 快捷键录入、冲突与提示**
  - 内容：#33 的设置页和实际按键提示。
  - 操作：打开设置 → 常规 → OCR，查看 OCR / 翻译界面快捷键，默认分别是 `Ctrl+O` / `Ctrl+T`。点击录入按钮，分别改成 `Ctrl+F8`、`Ctrl+F9`，等待自动保存；再试将两个按键设成相同、设成 `Ctrl+Z` 或某条全局热键，确认提示后改回有效按键。用截图热键框选，悬停 OCR / 翻译按钮并试按新快捷键。
  - 预期：录入过程有修饰键预览；冲突就地标红、不写入；合法修改自动保存；工具条提示与实际按键一致，重新打开设置仍保留。录入期间不会意外触发本程序的全局捕获。

- [ ] **2. 自动复制与文字输入保护**
  - 内容：#33 的 OCR、翻译操作体验。
  - 操作：在有文字的画面上分别测试工具条按钮与界面快捷键。关闭“识别后自动复制”时试 OCR / 翻译；开启后再试。翻译使用已经配置的服务；若未配置，检查配置引导即可。选中文字工具输入中文，输入期间按这两个快捷键。
  - 预期：关闭时打开结果面板；开启时不弹面板，OCR 复制识别文字，翻译只复制译文。翻译失败或没配置服务时通知原因、保留原剪贴板。输入标注文字时不跳到 OCR / 翻译。测试后将快捷键及开关恢复为自己的偏好。
