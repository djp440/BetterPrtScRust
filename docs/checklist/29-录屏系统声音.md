# 验收清单：#29 录屏录入系统声音

自动化已覆盖：时间轴对齐、补静音、重叠裁剪、暂停 / 继续、开关与绑定覆盖、GIF 无声、没有设备 / 编码器不支持 / 中途断开时的退回与通知（`crates/core/tests/recording_audio.rs`）；真机回环采集与 AAC 音轨（`audio_smoke`，2 秒视频的音轨与画面相差 7 毫秒）。下面只留需要人眼、人耳判断的项。

- [x] **1. 有声视频录屏，音画同步**
  - 操作：在浏览器里播放一段人说话的视频（或带节拍的音乐视频），用录屏热键框住画面录 20 秒左右，停止后用系统播放器打开生成的 MP4。
  - 预期：有声音；口型 / 节拍与声音对得上，肉眼看不出提前或滞后；结尾没有明显的空白或截断。
  - 用户反馈：

- [x] **2. 暂停、继续后仍同步**
  - 操作：同上录制，中途点录屏控制条“暂停”几秒再“继续”，重复两次，然后停止。
  - 预期：暂停期间的声音和画面都不在视频里；继续后的部分音画仍同步，衔接处没有错位或长段静音。
  - 用户反馈：

- [x] **3. 关掉系统声音**
  - 操作：在 `config.toml` 的全局设置里加 `record_system_audio = false`，保存后再录一段有声视频。
  - 预期：生成的 MP4 没有声音（播放器里没有音轨或无声），画面正常。验收完删掉这一行。
  - 用户反馈：

- [x] **4.（可选）没有输出设备**
  - 操作：在系统声音设置里禁用所有播放设备（或拔掉耳机且没有扬声器），再录一段。
  - 预期：开始录制时托盘通知“录屏没有声音”并说明原因；照常生成无声 MP4。验收完恢复设备。
  - 用户反馈：
