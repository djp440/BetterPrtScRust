# 窗口模式并入区域模式：单击选窗口，拖拽框选区域

此前捕获模式有显示器、虚拟桌面、区域、窗口四种：窗口模式单击选中顶层窗口，区域模式拖拽框选，两者各占一条热键（默认 Ctrl+PrtSc 是“窗口 + 等待确认”）。用户经常要先想清楚“这次是截窗口还是截区域”再选热键，而两种模式本来都在同一块选区遮罩上操作。现把窗口模式并入区域模式（#27）：

- 区域模式的遮罩上，还没有选区时指针下的顶层窗口高亮。按下左键后移动不超过系统拖拽阈值（`SM_CXDRAG` / `SM_CYDRAG`，按按下处显示器的缩放比例放大）就松开算单击：按下和松开在同一个窗口上时选中它；超过阈值则开始框选，照常吸附边缘。没有选区时按 Enter 选中高亮的窗口。
- 单击选中窗口后的去向与框选一致，按入口决定：
  - 截图：截后动作为复制到剪贴板时立即截取窗口完整内容并复制；等待确认时把窗口截图显示在遮罩上供标注。
  - 录屏：单击、框选都还要 Enter 或双击确认才开始；选中的是窗口时录这个窗口（跟随它移动），否则录区域。
  - 长截屏：选区取窗口在虚拟桌面内的范围，仍要点“开始”。
  - OCR：单击即识别窗口内容。
- 选中窗口后再调整选区（拖边、方向键微调），选区就不再是“这个窗口”，按普通区域处理。

配置里的 `mode = "window"` 不做兼容：与 ADR 0007 处理旧 `actions` 的方式相同，解析时报出指向该行的本地化错误（提示改成 `region`），整份配置回退到默认值。命令行 `bps capture window` 同样按未知模式拒绝。

## Consequences

- `CaptureMode` 只剩 `Display`、`VirtualDesktop`、`Region`；设置页的捕获模式下拉框去掉“窗口”。
- 默认的 Ctrl+PrtSc 改为“区域 + 复制到剪贴板”：单击窗口即复制窗口，拖拽即复制区域；PrtSc 仍是“区域 + 等待确认”。
- 命名模板的 `{mode}` 在单击选中窗口时也是 `region`；要区分窗口截图请用 `{window_title}`（框选时为空）。
- `SelectionOverlay` 新增 `drag_threshold()`（默认 4 × 4），Windows 实现读取系统设置。
- 原来独立的窗口选择状态机（`window_selection`）和窗口捕获流程（`window`）删除，逻辑并入 `RegionSelection` 与区域捕获。
